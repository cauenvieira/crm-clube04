\# Visão geral — Clube04 CRM



\## Objetivo



Criar um sistema próprio para gestão de leads, clientes da base, frequência, pacotes e ações comerciais do Clube04.



\## Prioridades do MVP



1\. Banco PostgreSQL com Docker.

2\. API Node.js.

3\. Webhook para receber leads/mensagens via n8n.

4\. Banco de conversas WhatsApp.

5\. Tela simples de leads.

6\. Ação do Dia.

7\. Estrutura para scraping autorizado do sistema Clube04.

8\. Motor de frequência e pacotes.



\## Fora do MVP inicial



\- Resposta automática por IA.

\- Envio automático massivo de WhatsApp.

\- Alteração automática de agenda no sistema Clube04.

\- Dashboard financeiro avançado.

\- Controle complexo de permissões.
