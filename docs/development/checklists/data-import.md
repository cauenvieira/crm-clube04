# Checklist - Data Import

- [ ] Source files and allowed tabs/sheets defined.
- [ ] Mapping and normalization rules documented.
- [ ] Dry-run script available before apply.
- [ ] Ambiguous records are reported, not auto-deleted.
- [ ] Import uses deterministic markers/runId.
- [ ] No real data is committed to repository.
- [ ] Rollback/remediation path documented.
- [ ] `npm run verify:all` executed sequentially after changes.
