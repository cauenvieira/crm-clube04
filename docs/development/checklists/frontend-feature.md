# Checklist - Frontend Feature

- [ ] Scope confirmed (view, interaction, API dependency).
- [ ] UI state handles loading, empty, and error.
- [ ] No horizontal overflow on desktop baseline.
- [ ] API key flow and secure local usage preserved.
- [ ] User actions have clear feedback.
- [ ] `docs/web/dashboard.md` updated if behavior changed.
- [ ] `npm run verify:dashboard` executed.
- [ ] `npm run verify:frontend` executed.
- [ ] `npm run verify:all` executed sequentially.
- [ ] Visual validation performed in browser tooling.
