\# Clube04 CRM



CRM operacional do Clube04 Mogi das Cruzes.



\## Objetivo



Substituir controles manuais de leads, recorrência, pacotes e follow-up por um sistema próprio integrado com n8n, WAHA e sincronização do sistema Clube04.



\## Módulos planejados



\- Captura de leads via n8n/WAHA

\- Banco de conversas WhatsApp

\- CRM de leads

\- CRM de clientes da base

\- Controle de frequência cadastrada e real

\- Controle de pacotes

\- Scraping autorizado do sistema Clube04

\- Ação do Dia

\- Dashboard



\## Ambiente local



Requisitos:



\- Docker Desktop

\- Git

\- Node.js LTS

\- Codex Desktop
